Replaying an effect adds no rewards. Meaningful practice earns separate Practice points. Scored XP follows a successful assessment; a milestone marks a named achievement.

What this preview simulates

The example has a skippable three-step tour. The hosted queue advances only when you simulate a free slot. Accounts, checks, rewards, notes, and runtime events use sample data. Nothing connects to a server.

Practice points: 5 per distinct meaningful activity per sample learning day, up to 30. Completing an example, submitting a repair, or explicitly recording a useful note qualifies. Drafts, launches, and replays do not. The browser challenge awards 50 XP once; examples and hosted checks award no scored XP.

A milestone preview illustrates a hypothetical assessed track completion. It does not claim that the one sample challenge completes a whole track. The production interface remains unchanged.
