User-selected scoring policy: one final submission with partial XP, not retry penalties.
Every permission request requires an explicit typed Allow/Deny decision. The server
saves the first valid submission, its fixture and correct/total counts. XP is the
integer floor of the time-based reward multiplied by correct/total: 4/6 within the
target earns 66 XP; 4/6 at twice the target earns 33 XP. Wrong decisions earn no
credit. The timer ends on submission. Only 6/6 completes the task; partial results
can be explicitly skipped while keeping XP, without adding a fully verified task.
Every result includes the expected decision, selected decision when known, and a
rule explanation. Disabled identities are denied before considering ownership/admin.

Migration 0007 adds permission_attempts and widens the XP constraint to 0–100.

unknown original choices; no selections are fabricated. Unfinished legacy puzzles
receive one final submission because earlier choices were not saved.
Reload, new-instance requests, pack edits, expiry and simultaneous submissions cannot
reset a saved result. Invalid/incomplete choices do not consume the one submission.
Ending a session before submitting continues to prevent XP.
