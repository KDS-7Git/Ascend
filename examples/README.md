# Example roadmaps

The complete TOML examples live in the canonical community pack directory:

- [Home hack lab](../packs/community/home-hack-lab.toml): build, test and harden a home lab.
- [Python file tool](../packs/community/python-file-tool.toml): build a tested command-line file organizer.
- [Blender first scene](../packs/community/blender-first-scene.toml): model, light and render a small still life.

Each pack uses external learning resources and concrete completion conditions.
These are AI drafts awaiting human review. Install a private copy, check the
resources, edit its variables, and review it before relying on its roadmap.
