# cloud-security: local practice files

These original Ascend fixtures contain synthetic data and are licensed with Ascend
under MIT. They are teaching inputs, not records of a real incident or a production
security implementation. The challenge specifies which files and commands to use.

1. Extract this archive into a new folder. Keep an untouched copy for comparisons.
2. Open a terminal in this folder (the one containing this README and report.py).
3. Check `python3 --version`. Windows users can use `py -3` instead of `python3`.
4. Read a script before running it. No script is started by downloading these files.
5. Follow the named challenge. `report.py` asks for your observations; it does not
   solve the exercise or grade reasoning. Supply the report path shown in Ascend.

Operational AD, mobile, Kubernetes, memory and radio exercises need their stated
external environment. A JSON model or static manifest cannot demonstrate a live
system's behavior. No paid course is required by this archive.

Ascend's file check sees the server filesystem. For remote/container deployments,
copy your report into the configured server lab directory. Saving it only on your
laptop will not make it visible to the checker. Keep unfinished work as progress.
