# Synthetic packet fixtures

Original MIT-licensed Ascend teaching inputs, generated by scripts/build_packet_fixtures.py without capturing or sending traffic.

http-training.pcap contains two HTTP exchanges with status 200 and 404, reserved documentation IP addresses and training.invalid. Both are benign. wifi-beacon.pcap (Networking ZIP only) contains one synthetic 802.11 beacon advertising Ascend-Training, channel 6 and WPA2/CCMP settings. It contains no association, handshake, radio metadata or actual device observations.

Open these named files in Wireshark. For SIEM import follow your supported Security Onion release documentation. A lack of alerts does not mean these benign requests were not ingested.

report.py is an optional notes helper; it does not solve or grade an exercise.
