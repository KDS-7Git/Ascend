## How it works

Git, dependency inputs, tests, artifact checksums and configuration.

A release record connects source revision, tested inputs and an artifact digest to what is actually running. A mutable tag or a directory name cannot establish that identity. Build in an owned workspace, preserve the inputs, and compare the deployed version with the recorded artifact before calling a release successful.
