## How it works

Triggers, runner identity, permissions, caches, artifacts and secret boundaries.

A CI job runs code with the runner's available identity and permissions. Untrusted pull-request code must not receive deployment credentials. A useful pipeline has a failing control and records which source/artifact passed. Syntax checks, runtime smoke checks and deployment gates answer different questions.
