## How it works

Staging, immutable promotion, release gates, concurrent releases and data compatibility.

Promotion should move the tested artifact into the target, not build a different artifact under the same name. Rollback restores an earlier release only when data/schema compatibility permits it. Keep state separate, serialize competing release changes, and test behaviour and version after promotion and recovery.
