## How it works

OpenTofu/provider boundary, plan/apply, state, drift and destruction.

Infrastructure as code records desired resources through a provider API. Plan is a proposal; apply changes the environment; state records mappings and can contain secrets. An owned libvirt sandbox offers useful practice without a cloud bill. Review provider identity/version and every proposed replacement before apply.

