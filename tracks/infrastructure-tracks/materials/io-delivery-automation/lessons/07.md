# 07. Configure a fleet

Configure two owned guests and run the same playbook again.

Author estimate: 90 minutes guided practice and 120 minutes independent work; split into sessions as needed. The portable preparation alone is usually 5–15 minutes. Setup, downloads and provider approval are separate.

Portable model: Python 3.11+ and an editor. Native operation: Ansible on the controller, two owned SSH Linux guests with guest sudo and a third non-target control; reviewed inventory and key paths.

## How it works

Ansible inventory, idempotence, privilege scope, secret handling and change limits.

Configuration automation acts with the permissions of its connection identity and privilege escalation. Inventory scope is therefore a boundary. Idempotence means a repeated run converges to the declared state without unintended repeated change, but it does not alone establish correct application behaviour.
