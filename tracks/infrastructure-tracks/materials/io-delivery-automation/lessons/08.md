Rebuild a clean target and deploy the same release using the recorded procedure.

Author estimate: 90 minutes guided practice and 120 minutes independent work; split into sessions as needed. The portable preparation alone is usually 5–15 minutes. Setup, downloads and provider approval are separate.

## Before starting

Portable model: Python 3.11+ and an editor. Native operation: A clean owned guest plus the earlier delivery tools, retained artifact/configuration and an application-consistent backup.

Download /training/io-delivery-automation.zip and extract it into a NEW folder you choose on your PC. Open a terminal in its io-delivery-automation directory; read README.md and bootstrap.md. Python 3.11+ runs the portable tools without extra Python packages. POSIX examples use Linux; Windows users can use a prepared Linux guest or WSL for the initial shell practice. Create work/ and notes/. Copy notes-template.md in your editor to notes/08.md, or append a dated attempt if the note already exists. Input files are in inputs/NN/, portable starting cases in cases/, operational instructions in lessons/NN.md, and the shared synthetic service in shared/. All generated work remains in the local paths printed by the tools. Opening a challenge does not create or upload these files. Use Ascend's notebook/upload control only when you choose to copy evidence into Ascend. Run commands one at a time on the named HOST, GUEST or CLIENT. Replace explicit address/key placeholders after inspection, and keep each foreground service in its own terminal. Stop its process with Ctrl+C before reusing the same listener.

Use only the named learner-owned environment. Commands that install packages or change services, networks, storage or VMs belong on that specified guest/host. A college-provided guest account is not permission to administer the physical host.

## How it works

Automation, release evidence, infrastructure ownership and runbooks.

A reproducible delivery path joins infrastructure, configuration, artifact identity and recovery. Someone else should be able to create a clean target from the retained inputs without your shell history. Rehearse an expired synthetic credential or bad release and identify which layer failed before changing everything.
