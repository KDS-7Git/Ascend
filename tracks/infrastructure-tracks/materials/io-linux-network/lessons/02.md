## How it works

Shell command structure, quoting, variables, pipes/redirection, stdout/stderr, paths, users/groups, environment, exit codes and signals.

The shell parses words before it starts a process. Quoting preserves spaces; pipes connect stdout to stdin; redirection opens a file and stdout/stderr are different streams. Permissions apply to identities and directories as well as a file. Solve the actual path or access problem rather than making all files world-writable.
