## How it works

Subnets, DHCP, ARP/neighbor discovery, routes, loopback and bind addresses.

A host decides whether a destination is on-link or needs a gateway using its address, prefix and routes. Loopback addresses refer to the current machine, and a loopback-bound server cannot serve a different guest. Guest Wi-Fi/client isolation may block peers even if each reaches the internet. Inspect both ends rather than treating all connection failures as a server defect.
