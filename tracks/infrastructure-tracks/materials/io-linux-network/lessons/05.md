## How it works

TCP, UDP, HTTP, TLS, connections, timeouts and certificate names.

Connection refusal means no acceptable listener at that address/port; a timeout can arise along the network path; an HTTP 500 proves an HTTP endpoint replied. TLS independently checks certificate trust and the expected name. Do not turn off certificate verification to make an HTTPS test pass.
