## How it works

Package repositories, updates, service installation, systemd, boot, users, health/readiness and durable state.

An interactive shell, a running process, an enabled service and a healthy service are different states. systemd starts a service with a defined identity, working directory and restart policy. Package repositories and updates supply executable code; record the distribution and package versions. A restart loop often exposes a path/configuration error rather than proving the machine needs more resources.

## Perform the operation

Predict the outcome, then run one block at a time on the named machine. A foreground server keeps running until you stop it; open the specified second terminal for its client checks. Shell comments describing a different terminal are instructions, not already executed commands.

### Operation 1

```sh
# Disposable Linux SERVICE GUEST only; package installation needs its administrator.
sudo apt-get update
sudo apt-get install python3
sudo useradd --system --home /opt/ascend-relay --shell /usr/sbin/nologin relaylab
sudo install -d -o relaylab -g relaylab /opt/ascend-relay/data /opt/ascend-relay/shared
sudo install -m 0644 shared/relay.py /opt/ascend-relay/shared/relay.py
sudo install -m 0644 inputs/07/relay.service /etc/systemd/system/ascend-relay.service
sudo systemctl daemon-reload
sudo systemctl enable --now ascend-relay.service
systemctl status ascend-relay.service --no-pager
journalctl -u ascend-relay.service -n 30 --no-pager
curl http://127.0.0.1:8000/version
```
