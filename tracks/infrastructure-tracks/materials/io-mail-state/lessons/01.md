## How it works

Application submission, SMTP envelope, headers, queues and delivery versus receipt.

An application submits an SMTP envelope and message headers; they can contain different identities. A local capture service helps debug application mail without delivering it to the internet. A captured message proves submission/capture, not mailbox access, SPF/DKIM verification or external deliverability.
