## How it works

SQLite/PostgreSQL roles, transactions, one-writer limits, mail storage and backup consistency.

Durable state needs a consistency boundary. SQLite WAL allows readers alongside a writer but still has a single-writer design; unrelated writable copies do not form a replicated database. Use the backup API rather than copying arbitrary live database/WAL files. Mailbox state similarly needs a known consistent backup procedure.
