## How it works

SSH host verification, user keys, agents, revocation and least privilege.

SSH authenticates the server identity and the user separately. A changed host key can mean reinstall, address reuse or an attack; verify the new fingerprint through the owned console before replacing a known_hosts record. A user key grants only the target account rights. Keep keys scoped, private and revocable, with a recovery path.
