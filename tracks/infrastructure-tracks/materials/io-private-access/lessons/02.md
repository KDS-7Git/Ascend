## How it works

SSH -L, listener binding, destination perspective and access restrictions.

A local SSH forward listens on the client and connects to the destination from the remote SSH server. The two loopback addresses therefore name different machines. Bind the client listener deliberately and restrict forwarding on the server where appropriate. Forwarding a port does not change application authorization.
