## How it works

Subnet routing, internet egress, split DNS, forwarding and route approval.

A subnet router advertises selected private routes; an exit node routes broader internet egress. Route acceptance, forwarding, return routes and DNS all matter. Do not turn a private-subnet task into full-tunnel egress merely because a default route seems easier. Verify exactly which traffic changes path.
