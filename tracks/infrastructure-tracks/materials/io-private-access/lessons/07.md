## How it works

Public HTTP versus client-assisted TCP/SSH and private network access.

A normal public HTTP tunnel can be visited in a browser. Documented Cloudflare TCP/SSH routes may require client-side cloudflared or a configured private-network client. Routing and identity enforcement remain separate. An ordinary HTTP tunnel is not a general public SMTP or arbitrary UDP listener.
