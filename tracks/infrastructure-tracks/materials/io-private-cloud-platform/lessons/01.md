## How it works

libvirt/Cockpit, Proxmox, Incus and OpenStack responsibilities; VM versus cloud API.

A cloud-style portal translates authenticated requests into hypervisor, storage and network operations. The guest keeps running under the host even when a browser closes; SSH enters the guest rather than the host management daemon. Begin with an existing platform before building a new portal, and identify which service owns each operation.
