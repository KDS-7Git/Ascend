## How it works

Images, cloud-init, identity, flavors, resource profiles and image lifecycle.

An image provides a common base; an instance profile chooses resources and network settings; per-instance initialization supplies unique identities. A project may share selected images/profiles or keep them isolated. CPU/memory shapes are allocations, not guaranteed requests-per-second figures.

### Operation 1

```sh
# OPERATOR, owned supported Incus Linux HOST only. Check KVM, free memory and disk first.
incus version
# For a fresh host use incus admin init interactively: a directory pool named default,
# a private managed bridge named incusbr0, and no public management listener.
# Existing installations: inspect and adapt to their chosen pool/network; do not reinitialize them.
incus storage list
incus network list
incus image list images: ubuntu/24.04
incus project create ascend-a -c features.images=true -c features.profiles=true -c features.networks=false
incus profile create lab-small --project ascend-a
incus profile set lab-small limits.memory=1GiB limits.cpu=1 --project ascend-a
incus profile device add lab-small root disk path=/ pool=default size=12GiB --project ascend-a
incus profile device add lab-small eth0 nic network=incusbr0 name=eth0 --project ascend-a
ssh-keygen -t ed25519 -f work/incus-learner-key
cp inputs/02/user-data work/incus-user-data
# Replace the PUBLIC-key placeholder, then inspect the file before passing it to cloud-init.
incus init images:ubuntu/24.04/cloud relay-a --vm --project ascend-a --profile lab-small
incus config set relay-a cloud-init.user-data - --project ascend-a < work/incus-user-data
incus config show relay-a --project ascend-a --expanded
incus start relay-a --project ascend-a
incus info relay-a --project ascend-a
incus exec relay-a --project ascend-a -- cloud-init status --wait
incus exec relay-a --project ascend-a -- ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
# Compare this trusted fingerprint on first SSH connection. Record guest type, address and identity.
# The cloud image alias is a concrete starting choice; confirm it exists for your architecture/version.
```
