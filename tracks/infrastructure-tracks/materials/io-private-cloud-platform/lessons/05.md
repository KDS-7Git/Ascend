## How it works

Floating/routed/bridged addresses, reverse proxy, guest perimeter and private access.

A running guest, a reachable management endpoint and a published website are separate states. Give the website a deliberate edge route while keeping host management private. Instance addresses may change after recreation; either discovery or a controlled address policy must update the route. A guest user must not need host administrator credentials to serve an application.
