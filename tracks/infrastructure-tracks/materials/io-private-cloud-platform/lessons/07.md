## How it works

VM lifecycle, container orchestration, Kubernetes requests/limits, scheduler and storage boundaries.

Kubernetes reconciles workloads and service endpoints; a VM manager owns guest machines and virtual devices. These control loops operate at different boundaries. A pod resource request affects scheduling while a limit constrains runtime use; a selected Service can route to no ready pods. Use a small separate cluster lab rather than stacking every control plane on the small server.
