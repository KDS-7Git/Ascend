## How it works

Static assets, dynamic requests, build output, runtime, state and platform contracts.

A static host returns built files; a dynamic service executes code for each request and may own durable state. The source project is not necessarily the deployable artifact. Build output paths, base URLs and runtime compatibility determine which hosting option can execute the project. Start by serving both models locally and observe the difference.
