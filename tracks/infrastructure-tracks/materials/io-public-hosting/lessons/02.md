## How it works

Reverse proxy, upstream address, headers, TLS termination, trust and names.

A reverse proxy owns the client-facing listener and forwards to an upstream. The site hostname is not the same as the listener bind; make both intentional. An upstream address is interpreted from the proxy machine. A loopback upstream cannot refer to a separate VM. Validate configuration before launch and compare direct origin versus edge responses.
