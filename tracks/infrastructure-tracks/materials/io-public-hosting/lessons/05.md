## How it works

Build pipelines, provider subdomains, repository visibility, paths and usage limits.

Free static publishing is still a public action with account, repository and usage conditions. Publish synthetic content through an eligible provider subdomain first. The chosen output directory and base path must match the platform. Secrets belong outside static build artifacts because every served file can be downloaded by visitors.
