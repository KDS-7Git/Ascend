## How it works

Execution compatibility, quotas, cold starts, runtime storage and database lifetime.

A free dynamic service has a runtime contract. A small Workers endpoint can be free under current limits, but is not a drop-in host for an arbitrary Python daemon. Other free web services may sleep or discard local files between instances. Verify current quotas, cold-start behaviour and persistence before choosing storage for user data.
