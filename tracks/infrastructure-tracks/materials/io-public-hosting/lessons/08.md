## How it works

LAN versus external clients, certificate/DNS state, origin availability and revocation.

Deployment diagnosis follows DNS, transport, TLS, edge, origin and state separately. A successful test on the same LAN can conceal broken external routing or a bad AAAA record. Preserve the version and data control while repairing the responsible boundary. Record the actual client network so others can reproduce the incident.
