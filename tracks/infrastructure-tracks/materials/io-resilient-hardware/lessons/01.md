## How it works

Boot, restart, time synchronization, readiness, monitoring location and failure domains.

Availability includes boot, service startup, dependencies, time, network and storage. A process that survives a terminal is not necessarily enabled at boot. An observer on the same machine cannot report while that machine has no power. Use a disposable guest for the software sequence and add physical observations only when you have the device.
