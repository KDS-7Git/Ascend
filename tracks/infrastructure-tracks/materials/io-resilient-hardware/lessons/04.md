## How it works

Write volume, flash endurance, swap pressure, tmpfs, durable state and SSD migration.

MicroSD capacity, write latency and endurance are different constraints. Logs, database journals, swap and build caches can write far more than the apparent user data. tmpfs can reduce writes only for data that may be lost, and consumes bounded RAM. Build and load-test on the PC while retaining necessary service state on appropriate durable storage.
