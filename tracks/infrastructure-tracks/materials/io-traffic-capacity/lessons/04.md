## How it works

I/O versus CPU work, threads, processes, async tasks, worker memory and pools.

Concurrency counts work in progress; parallelism counts simultaneous execution. I/O waits consume memory/connections without necessarily occupying a CPU. Threads, async tasks and processes have different overhead and CPU behavior. A per-application worker limit is not a global limit on sockets or OS threads.
