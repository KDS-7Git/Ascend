## How it works

Hardware virtualization, hypervisor, guest kernel, emulation, containers and nested virtualization.

The guest kernel sees virtual hardware supplied by a host process and hypervisor. A management application sends lifecycle requests; it does not need to remain visible for the guest to run. SSH is an independent service inside the guest. Hardware acceleration requires CPU, firmware, host kernel and permissions; emulation can run some foreign architectures but does not produce native performance evidence.
