## How it works

Guest process, private address, edge proxy, TLS and public-routing boundaries.

Website hosting in a VM uses the same process/socket mechanics as a physical host, but there is another virtual network boundary. Keep the origin private and place the intended edge in front. The host can route HTTP to the guest without exposing the guest management plane. Host, guest and external firewall settings have different authority.
